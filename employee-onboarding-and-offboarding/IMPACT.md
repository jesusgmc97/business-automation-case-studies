# Operational Impact

This production workflow coordinates employee lifecycle requests across Power Apps, SharePoint, HR documentation and internal business applications.

## Operational contribution

| Area | Contribution |
|---|---|
| Request intake | Structured data collection through a Power Apps form with validation checks |
| Document preparation | Population of the appropriate Word template and conversion to PDF |
| HR authorization | Document review, digital signature and the email validation action remain explicit stages |
| Document storage | Validated signed documents are filed in dedicated HR SharePoint folders |
| Communication | Email notifications reduce repeated manual updates |
| Record management | Automated creation of additional SharePoint records |
| System integration | Custom connectors support internal API operations and application updates |

## Human involvement

The process retains human effort for request entry, HR review, digital signature and explicit validation. These activities remain part of the total handling time.

## Quantitative scope

No measured processing times, monthly request volumes or verified time savings are reported in this case study.

The automation addresses repetitive administrative work, but the scale of the benefit depends on request volume, operation type and remaining human handling.

## Evaluation model

Onboarding and offboarding share the authorization pattern; their manual workloads can differ and are evaluated separately.

Estimated monthly administrative effort avoided:

```text
(Onboarding requests x reduction in manual handling minutes per onboarding)
+
(Offboarding requests x reduction in manual handling minutes per offboarding)
---------------------------------------------------------------------------
60
= Hours per month
```

Manual handling time includes the work performed by people before and after automation. Elapsed approval or signature waiting time is a separate measure of process duration.

Relevant operational indicators include request volume by operation type, manual handling time, time to HR approval, time to signed document archiving and cases requiring correction or intervention.
